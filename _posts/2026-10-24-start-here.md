你好，我是 Wone。这里是我的个人博客，也是我整理学习过程的地方。

我希望把文章写在 Markdown 文件里，让内容保持轻便、清楚，也方便以后修改。页面使用 Jekyll 生成，样式由 HTML 和 CSS 组成，计划通过 GitHub Pages 发布。

## 这里会写什么？

- 网页和样式实践中的收获
- 做项目时遇到的问题与解决过程
- 值得回头看的学习笔记和想法

我会尽量把过程写清楚，也会在有可以分享的作品时补上介绍和链接。希望这些记录能让我看见自己一步步学会了什么。
